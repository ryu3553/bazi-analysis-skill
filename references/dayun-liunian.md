# 大运流年

## 大运基础

大运是根据出生年干支和性别推算的，每10年一个大运。

### 起运时间计算

1. **阳年男命、阴年女命**：顺排
   - 从出生日起算到下一个节气的天数
   - 每3天折合1年
   - 顺排下一个干支

2. **阴年男命、阳年女命**：逆排
   - 从出生日起算到上一个节气的天数
   - 每3天折合1年
   - 逆排下一个干支

## 大运推算

### 排大运方法

大运从月柱干支开始推算，根据性别和出生年干的阴阳属性确定顺逆方向。

#### 顺排与逆排

| 出生年 | 性别 | 排法 | 说明 |
|--------|------|------|------|
| 阳年（甲丙戊庚壬） | 男 | 顺排 | 从月柱向下顺推 |
| 阳年（甲丙戊庚壬） | 女 | 逆排 | 从月柱向上逆推 |
| 阴年（乙丁己辛癸） | 男 | 逆排 | 从月柱向上逆推 |
| 阴年（乙丁己辛癸） | 女 | 顺排 | 从月柱向下顺推 |

#### 排大运示例

**示例1：阳年男命（顺排）**
- 出生年：甲子年（阳年）男命
- 月柱：丙寅
- 大运顺排：丁卯 → 戊辰 → 己巳 → 庚午 → 辛未 → 壬申 → ...

**示例2：阳年女命（逆排）**
- 出生年：甲子年（阳年）女命
- 月柱：丙寅
- 大运逆排：乙丑 → 甲子 → 癸亥 → 壬戌 → 辛酉 → 庚申 → ...

**示例3：阴年男命（逆排）**
- 出生年：乙丑年（阴年）男命
- 月柱：戊寅
- 大运逆排：丁丑 → 丙子 → 乙亥 → 甲戌 → 癸酉 → 壬申 → ...

**示例4：阴年女命（顺排）**
- 出生年：乙丑年（阴年）女命
- 月柱：戊寅
- 大运顺排：己卯 → 庚辰 → 辛巳 → 壬午 → 癸未 → 甲申 → ...

### 五虎遁月干（排月柱用）

> 注：以下口诀用于排月柱天干，非大运推算。大运从月柱起，按上述顺逆规则排布。

```
甲己之年丙作首，乙庚之年戊为头，
丙辛之年寻庚上，丁壬壬寅顺水流，
若问戊癸何处起，甲寅之上好追求。
```

| 年干 | 正月（寅月）天干 |
|------|------------------|
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

## 流年分析

### 流年与命局关系

1. **流年与日主**
   - 流年生日主：有贵人相助
   - 流年克日主：有压力、不顺
   - 流年与日主相同：有竞争、破财

2. **流年与大运**
   - 流年与大运相生：顺利
   - 流年与大运相克：不顺
   - 流年与大运相同：有竞争

3. **流年与命局**
   - 流年合入命局：有变化
   - 流年冲破命局：有动荡
   - 流年刑害命局：有是非

### 流年吉凶判断

| 流年 | 吉凶 | 说明 |
|------|------|------|
| 正印年 | 吉 | 有贵人、有学问 |
| 偏印年 | 半吉 | 有偏财、但孤独 |
| 正官年 | 吉 | 有地位、受尊重 |
| 七杀年 | 凶 | 有压力、易惹祸 |
| 正财年 | 吉 | 有正当收入 |
| 偏财年 | 半吉 | 有意外之财、但易浪费 |
| 食神年 | 吉 | 有才华、有口福 |
| 伤官年 | 凶 | 有口舌是非 |
| 比肩年 | 凶 | 有竞争、破财 |
| 劫财年 | 凶 | 有破财、婚姻不顺 |
