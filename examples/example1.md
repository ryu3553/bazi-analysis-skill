# 八字分析示例

## 示例1：1990年2月22日寅时

### 输入信息
- 公历：1990年2月22日 凌晨4点（04:00）
- 农历：庚午年 正月廿七 寅时

### 排盘结果

```
        年柱    月柱    日柱    时柱
天干：    庚      戊      戊      甲
地支：    午      寅      午      寅
```

**八字：庚午 戊寅 戊午 甲寅**

### 五行分析

| 五行 | 分数 | 强弱 |
|------|------|------|
| 土 | 35 | 旺 |
| 火 | 25 | 中等 |
| 木 | 25 | 中等 |
| 金 | 10 | 弱 |
| 水 | 5 | 极弱 |

**日主强弱**：戊土身旺

### 十神分析

| 位置 | 干支 | 十神 |
|------|------|------|
| 年干 | 庚 | 食神 |
| 年支 | 午 | 正印 |
| 月干 | 戊 | 比肩 |
| 月支 | 寅 | 七杀 |
| 日干 | 戊 | 日主 |
| 日支 | 午 | 正印 |
| 时干 | 甲 | 七杀 |
| 时支 | 寅 | 七杀 |

### 格局判断

**格局**：正印格

**用神**：金、水
**忌神**：火、土

### 大运流年

| 大运年龄 | 大运干支 | 吉凶 |
|----------|----------|------|
| 5-14岁 | 丁丑 | 中平 |
| 15-24岁 | 丙子 | 不利 |

| 35-44岁 | 甲戌 | 中平 |

| 55-64岁 | 壬申 | 大吉 |

### 命理建议

1. **适合职业**：金融、商业、技术
2. **注意事项**：早年压力大，中年后运势渐好
3. **健康注意**：脾胃和消化系统
4. **趋吉建议**：佩戴金属饰品，往西方发展

## 示例3：2000年1月15日子时（男命）

### 输入信息
- 公历：2000年1月15日 凌晨0点（00:00）
- 农历：己卯年 腊月初九 子时

### 排盘结果

```
        年柱    月柱    日柱    时柱
天干：    己      丁      壬      庚
地支：    卯      丑      申      子
```

**八字：己卯 丁丑 壬申 庚子**

### 五行分析

| 五行 | 分数 | 强弱 |
|------|------|------|
| 水 | 30 | 中等偏旺 |
| 金 | 25 | 中等 |
| 土 | 20 | 中等 |
| 木 | 15 | 弱 |
| 火 | 10 | 极弱 |

**日主强弱**：壬水身旺（得令于丑月、得地于申子）

### 十神分析

| 位置 | 干支 | 十神 |
|------|------|------|
| 年干 | 己 | 正官 |
| 年支 | 卯 | 伤官 |
| 月干 | 丁 | 正财 |
| 月支 | 丑 | 正官 |
| 日干 | 壬 | 日主 |
| 日支 | 申 | 偏印 |
| 时干 | 庚 | 偏印 |
| 时支 | 子 | 劫财 |

### 格局判断

**格局**：正官格

**用神**：木、火
**忌神**：金、水

### 刑冲合会分析

- **申子半合水局**：日支申 + 时支子 → 半合水，增强日主力量
- **卯申暗合**：年支卯 + 日支申 → 伤官合印，有才华但受压

### 神煞识别

- 年支卯 → 文昌贵人（壬日见寅，卯为文昌）
- 日支申 → 天乙贵人（壬癸日见卯巳，申为偏印）

### 命理建议

1. **适合职业**：技术、研究、学术
2. **注意事项**：印星旺，学业有成但需防依赖
3. **健康注意**：肾脏和泌尿系统
4. **趋吉建议**：往南方发展，多接触火元素
