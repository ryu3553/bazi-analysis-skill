## 干支计算方法

### 一、年干支计算

```
年干 = (公历年份 - 3) % 10     （余数 1=甲, 2=乙, ..., 0=癸）
年支 = (公历年份 - 3) % 12     （余数 1=子, 2=丑, ..., 0=亥）
```

> 注：以立春为界，立春前按上一年计算。

### 二、月干支计算（五虎遁）

**口诀**：
```
甲己之年丙作首，乙庚之年戊为头，
丙辛之年寻庚上，丁壬壬寅顺水流，
若问戊癸何处起，甲寅之上好追求。
```

**月支固定**（以节气为界）：

| 月份 | 月支 | 节气 | 月份 | 月支 | 节气 |
|------|------|------|------|------|------|
| 正月 | 寅 | 立春 | 七月 | 申 | 立秋 |
| 二月 | 卯 | 惊蛰 | 八月 | 酉 | 白露 |
| 三月 | 辰 | 清明 | 九月 | 戌 | 寒露 |
| 四月 | 巳 | 立夏 | 十月 | 亥 | 立冬 |
| 五月 | 午 | 芒种 | 十一月 | 子 | 大雪 |
| 六月 | 未 | 小暑 | 十二月 | 丑 | 小寒 |

**年干 → 正月（寅月）天干**：

| 年干 | 正月天干 | 年干 | 正月天干 |
|------|----------|------|----------|
| 甲、己 | 丙寅 | 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 | 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 | | |

### 三、日干支计算

**公式法（1900-2100年适用）**：

```
基数 = (年尾二位数 + 3) * 5 + 55 + (年尾二位数 - 1) / 4
日干支序数 = (基数 + 当年第几天) % 60

天干 = 日干支序数 % 10    （余数 1=甲, 2=乙, ..., 0=癸）
地支 = 日干支序数 % 12    （余数 1=子, 2=丑, ..., 0=亥）
```

**示例：2000年1月1日**
- 年尾：00
- 基数 = (0+3)*5 + 55 + (0-1)/4 = 15 + 55 + 0 = 70
- 1月1日 = 当年第1天
- 日干支序数 = (70 + 1) % 60 = 71 % 60 = 11
- 天干 = 11 % 10 = 1 → 甲
- 地支 = 11 % 12 = 11 → 戌
- 结果：甲戌日

### 四、时干支计算（五鼠遁）

**口诀**：
```
甲己还加甲，乙庚丙作初，
丙辛从戊起，丁壬庚子居，
戊癸何方发，壬子是真途。
```

**日干 → 子时天干**：

| 日干 | 子时天干 | 日干 | 子时天干 |
|------|----------|------|----------|
| 甲、己 | 甲子 | 乙、庚 | 丙子 |
| 丙、辛 | 戊子 | 丁、壬 | 庚子 |
| 戊、癸 | 壬子 | | |

**示例：甲日**
- 子时：甲子 → 丑时：乙丑 → 寅时：丙寅 → 卯时：丁卯 → ...
