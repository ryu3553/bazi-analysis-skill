# 八字命理分析 Skill

专业的八字命理分析 Skill，提供传统八字知识、规则组织和结构化解释。项目将**确定性计算**与**命理解释**分离：历法、节气、四柱和起运等精确计算应由经过验证的计算模块提供，Skill 负责规则引用、分析流程和自然语言解释。

## ✨ 功能特性

### 分析功能
1. **四柱分析** - 使用已验证的年柱、月柱、日柱、时柱
2. **五行分析** - 天干、地支、藏干、月令及旺衰综合分析
3. **十神分析** - 基于日主分析天干与藏干的十神关系
4. **格局分析** - 身强身弱、格局、用神与忌神
5. **调候分析** - 根据季节和传统规则分析调候
6. **大运流年** - 基于已验证的起运与排运结果进行解释
7. **刑冲合会** - 天干五合及地支合、冲、刑、害、三合、三会等
8. **神煞识别** - 作为辅助分析信息
9. **纳音五行** - 作为补充信息
10. **十二长生** - 分析日主在地支中的状态

## 🧭 设计原则

### 计算与解释分离

项目目前主要是 Skill + references，而不是完整的历法计算程序：

```text
出生信息
   ↓
确定性历法/排盘计算模块（后续加入）
   ↓
结构化四柱数据
   ↓
命理规则 / references
   ↓
分析 Skill
   ↓
结构化解释
```

在没有经过验证的计算模块时，不应声称“精确计算”四柱或给出未经验证的精确起运时间。

### 可追溯

重要结论应尽量遵循：

```text
原始数据 → 规则 → 中间判断 → 结论 → 不确定性
```

### 流派隔离

不同传统流派的规则应明确标注来源，不应在没有说明的情况下混合成一个不可追溯的“综合算法”。

## 📚 理论基础

参考传统命理经典，包括：

- 《三命通会》
- 《渊海子平》
- 《滴天髓》
- 《穷通宝鉴》
- 《子平真诠》
- 《千里命稿》
- 《命理探原》

references/ 中进一步保存天干地支、五行、十神、大运流年、刑冲合会、神煞等专题资料。

## 🚀 使用方法

当用户提到以下主题时可以触发：

- 八字、命理、算命、生辰八字
- 四柱、五行、十神、大运、流年
- 命盘、排盘

### 推荐输入

```text
出生日期：1990年5月15日
出生时间：上午10点
出生地点：北京
历法：公历
性别：男
```

如果缺少影响计算的重要信息，应先询问，而不是猜测。
