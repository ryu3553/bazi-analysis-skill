# 五行生克关系

## 五行相生

| 相生关系 | 说明 | 例子 |
|----------|------|------|
| 木生火 | 木燃烧生火 | 钻木取火 |
| 火生土 | 火燃烧后成灰烬 | 焚烧成灰 |
| 土生金 | 土中藏金属 | 矿石提炼 |
| 金生水 | 金属凝结水珠 | 金属表面凝水 |
| 水生木 | 水滋养树木 | 植物生长 |

### 日主强弱判断标准

1. **得令** - 日主在月令中处于旺相状态
2. **得地** - 日主在地支中有根（地支藏干中有同类）
3. **得生** - 八字中有印星生扶日主
4. **得助** - 八字中有比劫帮助日主

满足2-3项为身强，满足0-1项为身弱。

## 五行与性格

### 木
- 仁慈、正直、有同情心
- 善良、有同情心
- 固执、缺乏变通

### 火
- 热情、急躁、有礼貌
- 聪明、有创造力
- 冲动、缺乏耐心

### 土
- 诚实、稳重、有信用
- 包容、有责任感
- 固执、缺乏灵活

### 金
- 果断、刚毅、有正义感
- 精明、有组织能力
- 冷酷、缺乏人情

### 水
- 聪明、灵活、有智慧
- 善变、有适应能力
- 多疑、缺乏主见
