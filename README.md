# 八字命理分析 Skill

专业的八字命理分析 Skill，提供传统八字知识、规则组织和结构化解释。项目将**确定性计算**与**命理解释**分离。

## 当前可用：P0 四柱测试计算器

在 `feat/p0-four-pillars` 分支中，可以直接输入公历出生日期和时间测试四柱：

```bash
pip install -r requirements.txt
python -m src.calendar.cli 1990-05-15 10:30
```

输入的是**当地民用时间**。程序会输出年柱、月柱、日柱、时柱。

历法计算使用 `sxtwl`；当前支持 1900–2100 年，暂不自动进行真太阳时修正。后续会加入时区/地点和可选真太阳时处理。

## 设计原则

计算层负责确定性数据；Skill 负责规则组织和自然语言解释。无法验证的数据不猜测、不伪造精确结果。

重要结论尽量遵循：

```text
原始数据 → 规则 → 中间判断 → 结论 → 不确定性
```
