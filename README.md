# 八字命理分析 Skill

专业的八字命理分析工具，融合民国命理大师的理论精髓，支持完整的四柱八字计算和解读。

## ✨ 功能特性

### 核心功能
1. **四柱八字计算** - 根据出生年月日时精确计算天干地支
2. **五行分析** - 统计金木水火土的分布和强弱，计算五行分数
3. **十神分析** - 分析日主与其他干支的关系
4. **大运流年** - 推算大运和重要流年
5. **命理建议** - 基于八字格局给出趋吉避凶建议

### 扩展功能
6. **刑冲合会** - 分析地支之间的刑冲合会关系
7. **神煞识别** - 识别命局中的吉神凶煞
8. **纳音五行** - 分析纳音五行属性
9. **十二长生** - 分析日主在地支的状态
10. **格局分析** - 判断身强身弱、用神忌神

## 🔧 技术实现

### 分析流程

1. **排盘**：根据出生年月日时计算四柱八字
2. **五行分析**：统计五行分数，判断日主强弱
3. **十神分析**：分析十神关系和组合
4. **格局判断**：确定格局类型和用神
5. **大运流年**：推算大运和流年运势
6. **调候用神**：根据季节判断调候需求
7. **刑冲合会**：分析地支关系
8. **神煞识别**：识别吉凶神煞
9. **纳音五行**：分析纳音属性
10. **十二长生**：分析日主状态

### 算法说明

- **五行分数**：根据天干地支的五行属性计算分值
- **日主强弱**：综合考虑月令、通根、生扶等因素
- **格局判断**：根据月令和十神组合确定格局
- **大运推算**：根据性别和出生年干支顺逆排布
